# โครงเว็บจองพื้นที่อ่านหนังสือ

เว็บตัวอย่างแบบ structure-first ตาม user flow ใน `User Flow-2.pdf` ยังไม่มีการออกแบบ UI หรือเชื่อม backend ใช้ข้อมูลพื้นที่จำลองเพื่อเดินดูขั้นตอนและความสัมพันธ์ระหว่างหน้าจอ

## เปิดดู

เปิดเว็บจาก static server ที่ root ของโปรเจกต์ เช่น:

```sh
python3 -m http.server 8000
```

จากนั้นเข้า `http://localhost:8000`

## โครงสร้างไฟล์

- `index.html` จุดเริ่มต้นของเว็บ
- `src/main.js` เริ่มต้นแอป
- `src/app.js` หน้าจอและการเปลี่ยนขั้นตอนของ user flow
- `src/data/flow.js` รายการขั้นตอนและ onboarding
- `src/data/spaces.js` ประเภทพื้นที่และข้อมูลตัวอย่าง
- `src/styles.css` สไตล์พื้นฐานสำหรับอ่านโครงสร้าง ยังไม่ใช่ UI design

## Flow ที่ทำเป็นโครงไว้

เข้าสู่ระบบด้วยอีเมล `@mail.kmutt.ac.th` หรือเลือก Google / Microsoft / ModLink → หน้าหลัก/ค้นหา → รายการพื้นที่และตัวกรอง → รายละเอียดพื้นที่ → เลือกวัน เวลา และที่นั่ง → ตรวจสอบสถานะว่าง → ทางเลือกเมื่อเต็ม → ตรวจสอบการจอง/ผู้ร่วมใช้ → ยืนยันและ QR code → รายการจอง → รายละเอียด เช็กอิน ขยายเวลา เปลี่ยนแปลง หรือยกเลิก

ข้อมูลการจองและ QR code เป็นตัวอย่างในหน่วยความจำของหน้าเว็บ ยังไม่บันทึกถาวร ระบบล็อกอินและปุ่ม Google / Microsoft / ModLink ยังไม่เชื่อมต่อผู้ให้บริการจริง
